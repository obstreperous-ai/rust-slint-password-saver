# Code Quality Tools

This document describes the code quality tools and configurations set up for this project.

## Tools Overview

### 1. Rustfmt (Code Formatting)

Configuration file: `rustfmt.toml`

Rustfmt is the official Rust code formatter that ensures consistent code style across the project.

**Usage:**
```bash
# Check if code is formatted correctly
cargo fmt -- --check

# Automatically format all code
cargo fmt
```

**Configuration:** The `rustfmt.toml` file contains formatting rules including:
- Maximum line width: 100 characters
- 4 spaces for indentation
- Automatic import reordering

### 2. Clippy (Linting)

Configuration: `[lints.clippy]` section in `Cargo.toml`

Clippy is Rust's official linter that catches common mistakes and suggests improvements.

**Usage:**
```bash
# Run clippy with warnings as errors
cargo clippy --all-targets -- -D warnings

# Run clippy and see suggestions
cargo clippy --all-targets
```

**Configuration:** The project uses:
- Pedantic lint group enabled as warnings
- Some overly strict lints are allowed (e.g., `uninlined_format_args`, `items_after_statements`)

### 3. Cargo Audit (Security Vulnerability Scanner)

Cargo audit checks dependencies against the RustSec advisory database for known security vulnerabilities.

**Installation:**
```bash
cargo install cargo-audit
```

**Usage:**
```bash
# Check for security vulnerabilities in dependencies
cargo audit
```

### 4. Pre-commit Hooks

Configuration file: `.pre-commit-config.yaml`

Pre-commit hooks run automated checks before each commit to catch issues early.

**Installation:**
```bash
# Install pre-commit tool (requires Python)
pip install pre-commit

# Install the git hook scripts
pre-commit install
```

**Usage:**
```bash
# Pre-commit hooks run automatically on git commit

# Run manually on all files
pre-commit run --all-files

# Update hook versions
pre-commit autoupdate
```

**Configured Hooks:**
- Trailing whitespace removal
- End-of-file fixer
- YAML/TOML syntax validation
- Large file detection
- Merge conflict detection
- Rust formatting check (`cargo fmt`)
- Rust linting (`cargo clippy`)
- Security audit (`cargo audit`)

## CI/CD Integration

All code quality tools are integrated into GitHub Actions workflows:

### `.github/workflows/quality.yml`
- Runs on every push and pull request
- Executes format checks with `cargo fmt -- --check`
- Runs clippy linting with `cargo clippy --all-targets -- -D warnings`

### `.github/workflows/security.yml`
- Runs on pushes affecting Cargo files
- Scheduled to run daily
- Executes `cargo audit` to check for vulnerabilities

## Best Practices

1. **Before Committing:**
   - Run `cargo fmt` to format your code
   - Run `cargo clippy` to check for linting issues
   - Pre-commit hooks will run automatically if installed

2. **During Development:**
   - Run clippy frequently: `cargo clippy --all-targets`
   - Address warnings as they appear
   - Keep dependencies up to date

3. **Security:**
   - Run `cargo audit` periodically to check for vulnerabilities
   - Update dependencies when security advisories are released
   - Review the CI security workflow results

4. **Pull Requests:**
   - All quality checks must pass before merging
   - Address all clippy warnings
   - Ensure code is properly formatted

## Troubleshooting

### Pre-commit hooks fail
If pre-commit hooks fail:
```bash
# Skip hooks in emergency (not recommended)
git commit --no-verify

# Update pre-commit hooks
pre-commit autoupdate

# Clean cache and retry
pre-commit clean
pre-commit run --all-files
```

### Clippy warnings in generated code
Some warnings may appear in code generated by `slint-build`. These are excluded by adjusting the clippy configuration in `Cargo.toml`.

### Cargo audit warnings
If cargo audit reports warnings about unmaintained crates in dependencies:
- Check if the dependency is indirect (coming from another crate)
- Consider opening an issue with the direct dependency maintainer
- Monitor for updates that address the issue
